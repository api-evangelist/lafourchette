# LaFourchette (TheFork)

> LA FOURCHETTE SAS, trading as TheFork, is the European restaurant-booking and restaurant-management
> platform (founded Paris 2007, acquired by TripAdvisor 2014). It publishes two REST APIs at
> docs.thefork.io: the B2B / Partners API for restaurant groups, CRM platforms and booking-funnel
> partners, and the POS API v1 for point-of-sale vendors. Credentials are issued by TheFork's
> integrations team — there is no self-serve signup and no sandbox you can enter alone.

Generated by API Evangelist on 2026-08-17. TheFork serves no /llms.txt of its own
(https://docs.thefork.io/llms.txt returns 403, https://www.thefork.com/llms.txt returns 404), so this

## What an agent needs to know first

- **You cannot self-serve.** Both APIs require credentials issued by integrations@thefork.com after a
  partner approval. There is no free tier, no test key and no public sandbox.
- **Two different auth models.** B2B: OAuth 2.0 client-credentials at
  `https://auth.thefork.io/oauth/token` with `audience=https://api.thefork.io`, presented as
  `Authorization: Bearer <access_token>` (8600s TTL; TheFork asks you not to mint a new token before
  the old one expires). POS: an `X-Api-Key` header.
- **No idempotency.** No write operation takes an idempotency key, including reservation creation.
  A duplicate create surfaces only as `409 DOUBLE_BOOKING`.
- **List then fetch.** The list operations return arrays of UUIDs, not objects. Page with
  `page`/`limit`, then call the `/{id}` detail operation per record.
- **Errors are not RFC 9457.** The envelope is `{ statusCode, error, data: { code } }`; match on
  `data.code` (RESERVATION_NOT_FOUND, DOUBLE_BOOKING, CANCELLATION_ERROR, …).
- **Rate limits are contractual and unpublished.** Only the failure signal (429) is documented.

## APIs

- [TheFork B2B API](https://docs.thefork.io/B2B-API/introduction): reservations, customers, reviews,
  availabilities, offers, timeslots, party sizes, caller recognition. Base
  `https://api.thefork.io/manager`. 18 operations.
- [TheFork POS API v1](https://docs.thefork.io/POS-API/introduction): register a POS instance, upload
  a logo, close orders back onto a reservation. Base `https://api.thefork.io/pos`. 3 operations plus
  one inbound callback the POS vendor must serve.
